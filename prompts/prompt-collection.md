# 📝 100+ AI Prompt Collection

## Writing

### Blog/Viral Articles
```
Write a 1500-word article about [topic]. Use a conversational tone.
Open with a surprising statistic. Include 3 subheadings.
End with a call to action for comments and shares.
```

### Social Media Posts
```
Write 5 Xianyu listing descriptions for [product].
Each under 200 characters. Use emojis.
Highlight value for money. End with "Limited time offer!"
```

### Xiaohongshu (RED) Content
```
Write a Xiaohongshu post promoting [product/service].
100-150 characters. Use emojis. Share personal experience.
Add 3-5 relevant hashtags. End with engagement call.
```

### Resume Bullet Points
```
Rewrite these resume points to be more professional:
[paste resume]
Use action verbs. Include quantified achievements where possible.
```

## Business

### Business Plan
```
Create a one-page business plan for [idea].
Include: target audience, value proposition,
revenue model, 3-month action plan.
```

### Cold Email
```
Write a cold outreach email to [target audience].
Subject line should create curiosity.
Keep body under 100 words. Include clear CTA.
```

### Product Description
```
Write an Amazon product description for [product].
Include: 5 bullet points, 200-word description.
Use SEO keywords naturally.
```

## Coding

### Code Generation
```
Write a [language] function that [description].
Include error handling and comments.
Follow best practices.
```

### Bug Fix
```
This code has a bug: [paste code]
The expected behavior is [description].
The actual behavior is [description].
Find and fix the issue.
```

### Code Review
```
Review this code for:
1. Security vulnerabilities
2. Performance issues
3. Code style improvements
4. Edge cases not handled
```

## Design

### Logo/Brand
```
Design brief for [company name]:
Industry: [industry]
Target audience: [description]
Brand personality: [3 adjectives]
Color preferences: [colors]
```

### UI/UX
```
Suggest improvements for this user flow:
[describe flow]
Focus on reducing friction and improving conversion.
```

## Marketing

### Ad Copy
```
Write 3 Facebook ad variations for [product].
Each: headline (30 chars) + body (125 chars) + CTA.
Target audience: [description].
```

### SEO Content
```
Write SEO-optimized content about [keyword].
Include: H1, H2 subheadings, meta description (155 chars).
Target keyword density: 1-2%.
Natural internal linking suggestions.
```

## Video

### Short Video Script
```
Write a 30-second TikTok script for [product].
First 3 seconds: hook (pain point / curiosity / conflict).
Middle: show product benefits.
End: call to action.
```

### YouTube Description
```
Write a YouTube video description for [video topic].
Include: 100-word summary, timestamps,
relevant links, 5-10 hashtags.
```

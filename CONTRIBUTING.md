# Contributing to Awesome Free AI Tools

Contributions welcome! Here's how:

## Adding a Tool
1. Check it's not already listed
2. Verify it has a real free tier
3. Add to the correct category in README.md
4. Include: name, URL, price, best use case

## Adding a Guide
1. Create a new .md file in `/guides/`
2. Include practical, actionable steps
3. Add income estimates where possible

## Adding Prompts
1. Add to `/prompts/prompt-collection.md`
2. Include the use case and category
3. Test the prompt works before submitting

## PR Process
1. Fork → branch → commit → PR
2. Keep PRs focused (one tool/guide/prompt per PR)
3. Update the table of contents if adding sections
